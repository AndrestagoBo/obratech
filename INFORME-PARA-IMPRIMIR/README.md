# Informe técnico de ObraTech

Esta carpeta está separada del código de la aplicación. No cambia el funcionamiento ni el diseño del sitio.

## Cómo imprimir

1. Abra `manual-tecnico.html` con Chrome, Edge o Firefox.
2. Pulse **Imprimir / Guardar PDF** en la portada.
3. En la ventana de impresión use:
   - Papel: A4 o Carta.
   - Escala: 100 %.
   - Márgenes: Predeterminados.
   - Gráficos de fondo: activados.
4. Elija una impresora o **Guardar como PDF**.

## Qué contiene

- Explicación funcional para una persona no técnica.
- Arquitectura y recorrido de los datos.
- Inventario de páginas, componentes, APIs y archivos.
- Funcionamiento del asesor, panel administrativo y almacenamiento.
- Seguridad, límites actuales y riesgos de producción.
- Guía de ejecución local, red Wi-Fi, pruebas, publicación y mantenimiento.
- Lista priorizada de acciones pendientes.
