# ObraTech Bogotá

Sitio de servicios para el hogar y obra. Cotización por WhatsApp. Chat con motor de reglas (sin IA de pago). Leads en `/admin`.

## Documentación

- Producto, APIs: [DOCUMENTACION.md](./DOCUMENTACION.md)
- Asesor del hogar (chat): [DOCUMENTACION-CHAT.md](./DOCUMENTACION-CHAT.md)
- Panel admin: [DOCUMENTACION-ADMIN.md](./DOCUMENTACION-ADMIN.md)
- Interfaz gráfica (marca, color, componentes): [DOCUMENTACION-UI.md](./DOCUMENTACION-UI.md)

## Arranque

```bash
npm install
npm run dev
```

- Sitio: http://localhost:3000
- Admin: http://localhost:3000/admin
- Vista diseño (sin chat ni formulario): http://localhost:3000/diseno
